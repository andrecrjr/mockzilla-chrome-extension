Substring

pattern: /todos/1
Exemplo: /todos/1 casa com .../todos/1
Regras sugeridas
[ { "id": "match-test-substring-todos-1", "name": "Match Test: substring /todos/1", "matchType": "substring", "pattern": "/todos/1", "bodyType": "json", "body": "{\"matched\":\"substring\"}", "statusCode": 200, "enabled": true } ]

Exact

pattern: https://.../todos/1
Exemplo: casa só com a URL exata (query muda tudo)
Regras sugeridas
[ { "id": "match-test-exact-todos-1", "name": "Match Test: exact todos/1", "matchType": "exact", "pattern": "https://jsonplaceholder.typicode.com/todos/1", "bodyType": "json", "body": "{\"matched\":\"exact\"}", "statusCode": 200, "enabled": true } ]
